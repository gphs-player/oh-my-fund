# 投资计划字段重构设计

## 概述

调整投资计划的字段：移除"标签"，新增"场内外"和"市场"两个字段。市场列表存储在服务端 CSV 文件，前端可编辑并同步。

## 字段变更

### 移除
- `tags` (标签)

### 新增
- `trade_type`: 场内外，枚举值 `["场内", "场外"]`，必填
- `market`: 市场，字符串，从市场列表中选择，必填

### 表格列顺序
基金名称、基金代码、板块、仓位金额、仓位占比、**场内外**、**市场**、风险等级、持有计划、操作

## 后端实现

### 新增 API

```
GET  /api/markets  — 获取市场列表，返回 JSON 数组
POST /api/markets  — 保存市场列表（全量覆盖），接收 JSON 数组
```

### 新增文件

```
data/markets.csv  — 市场列表持久化存储
```

### 初始数据

```csv
name
美股
A股
亚太
港股
全球
```

### 容错
- `data/` 目录不存在时自动创建
- `markets.csv` 不存在时自动创建并写入默认值

## 前端实现

### 表格显示
- 场内外：徽章样式，场内 `badge-info`，场外 `badge-warning`
- 市场：纯文本

### 模态框
- 移除"标签"输入框
- 新增"场内外"下拉框（必填，无默认值）
- 新增"市场"下拉框（必填，动态从 API 获取选项）

### 工具栏
- 新增"管理市场"按钮（在"导出CSV"后面）
- 点击弹出管理市场模态框

### 管理市场模态框
- 显示当前市场列表
- 每项有删除按钮
- 底部输入框 + 添加按钮
- 保存按钮同步到服务端

## CSV 导入导出

### 导出字段
`fund_name, fund_code, sector, position, trade_type, market, risk_level, holding_plan`

### 导入兼容
- 支持字段名：`trade_type` / `场内外`，`market` / `市场`
- 旧 CSV 缺少新字段时设为空

## 数据迁移

- localStorage 旧数据自动忽略 `tags` 字段
- 新字段缺失时设为空字符串
- 表格中空值显示为 `-`

## 初始化流程

1. 页面加载 → `GET /api/markets` 获取市场列表
2. 从 localStorage 加载投资数据
3. 渲染表格
