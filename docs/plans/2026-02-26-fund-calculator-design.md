# 基金理财系统框架设计文档

## 项目概述

基于Python Flask的个人基金理财系统，采用后端渲染架构，所有业务逻辑在前端完成，后端仅提供静态页面服务。

## 技术栈

### 后端
- **Web框架**: Flask（仅渲染首页HTML）
- **模板引擎**: Jinja2

### 前端
- **UI框架**: Tailwind CSS + DaisyUI
- **图表库**: Chart.js（饼图 + 折线图）
- **脚本**: Vanilla JavaScript
- **UI风格**: 毛玻璃效果 + 科技感动画

### 数据存储
- CSV文件（前端导入导出，浏览器内存/localStorage管理）

## 架构设计

### 整体架构
采用传统MPA（多页应用）架构，实际上是单页面应用：
- Flask启动后提供一个HTML页面
- 所有功能通过前端JavaScript实现
- 无需数据库，无需后端API
- 用户数据通过CSV文件导入导出管理

## 功能设计

### 页面布局
首页采用Tab标签页切换三个功能模块（DaisyUI tabs组件）：
- **Tab1**: 投资计划（默认展示）
- **Tab2**: 年化计算器
- **Tab3**: 复利计算器

### 1. 投资计划模块

#### 功能特性
- 表格展示所有投资记录
- 支持添加、编辑、删除记录
- 仓位列可点击排序（升序/降序）
- 自动计算仓位占比（该项仓位 / 总仓位 × 100%）
- 表格底部显示汇总行（总仓位、总占比100%）
- CSV导入导出功能
- 数据可视化（4个维度的饼图）

#### 数据字段
- 基金名称（字符串）
- 基金代码（5-8位数字）
- 板块（字符串）
- 仓位（数字）
- 风险等级（高/中高/中/低）
- 持有计划（长期/中期/短期）
- 标签（字符串，可选）

#### 表格结构
```
| 基金名称 | 基金代码 | 板块 | 仓位↑↓ | 仓位占比 | 风险等级 | 持有计划 | 标签 | 操作 |
```

#### 数据可视化
- 4个维度切换按钮：板块/仓位/风险等级/持有计划
- Chart.js渲染交互式饼图
- 前端按选定维度分组统计数据

#### CSV文件管理
- 文件命名格式：`investments_YYYYMMDD_HHMMSS.csv`
- 导入：前端File API读取CSV文件，解析后加载到内存
- 导出：前端生成带时间戳的CSV文件供下载
- 数据存储：浏览器localStorage持久化（可选）

#### 前端实现逻辑
1. 页面加载时从localStorage读取数据（如果有）
2. 用户可导入CSV覆盖当前数据
3. 所有增删改查在内存数组中操作
4. 排序、占比计算、图表渲染都在前端完成
5. 用户点击导出时生成CSV文件下载

### 2. 年化计算器

#### 功能特性
- 两种计算方式的子Tab切换
- 即时计算，结果显示在页面上

#### 计算方式
**方式1：根据持有周期、总收益率计算**
- 输入：持有周期（天数）、总收益率（%）
- 输出：年化收益率（%）
- 公式：年化收益率 = (1 + 总收益率) ^ (365 / 持有天数) - 1

**方式2：根据期初净值、持有周期、期末净值计算**
- 输入：期初净值、持有周期（天数）、期末净值
- 输出：年化收益率（%）
- 公式：先计算总收益率 = (期末净值 - 期初净值) / 期初净值，再用方式1公式

### 3. 复利计算器

#### 功能特性
- 动态投资项列表（可添加/删除多个投资项）
- 计算年限默认值：20年
- Chart.js绘制多条折线图对比
- 显示数据表格

#### 输入参数
- 计算年限（默认20年）
- 投资项列表（每项包含）：
  - 投资项名称
  - 初始金额
  - 预计年化收益率（%）
  - 年末追加金额

#### 输出结果
- 折线图：横轴为年份，纵轴为资产总额，每个投资项一条线
- 数据表格：每年每个投资项的详细数据

#### 计算公式
```
第N年资产 = (第N-1年资产 + 年末追加金额) × (1 + 年化收益率)
第1年资产 = 初始金额 × (1 + 年化收益率)
```

## 技术实现要点

### CSV处理（前端）
- 使用File API读取文件
- 手动解析CSV格式或使用轻量级库（如PapaParse）
- 生成CSV使用Blob + URL.createObjectURL下载

### 数据持久化
- 使用localStorage存储当前数据
- 页面刷新后自动恢复
- 用户可随时导出备份

### Chart.js配置
- 饼图：响应式、显示百分比、图例
- 折线图：多数据集、网格线、工具提示

### 表格排序
- 监听表头点击事件
- JavaScript数组sort方法
- 重新渲染表格DOM

### 数据验证
- 基金代码：5-8位数字正则验证
- 仓位：0-100数字范围验证
- 必填字段检查
- CSV格式验证

## 总结

本设计采用极简架构，后端仅提供静态页面服务，所有业务逻辑在前端实现。优点是部署简单、无需数据库、用户数据可控；缺点是不支持多用户、数据存储依赖浏览器。适合个人本地使用的理财工具场景。
